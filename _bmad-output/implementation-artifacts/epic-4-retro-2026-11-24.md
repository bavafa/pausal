## What got done

- `pnpm decide --check` now fails when a clip video or a product image file is missing under `apps/web/public` (commit `dacc1a7`, two new tests). This was Epic 1 to-do item 3. It matters for Epic 4, because real clips and product images land there.
- The Alibaba Model Studio data terms are summarised in `docs/data-sources.md`. Their docs say API inputs and outputs are not used to train models. They do not say clearly how long plain API calls are kept, so only AI-generated clips are sent for now.
- The ABO catalog is downloaded to `data/catalog/`, which git ignores (about 3.3 GB). Both download files contain the same licence file: plain CC BY 4.0, with no non-commercial wording. That answers the worry about older CC BY-NC text on some Amazon pages.
- Both API keys work. `qwen3.7-flash` answered a tiny test in 3.3 seconds and `qwen3.7-plus` in 5.0 seconds. Jev accepted its key.
- `.env.example` lists the three settings the pipeline needs: `DASHSCOPE_API_KEY`, `DASHSCOPE_BASE_URL` and `TYPESAFE_API_KEY`.
- Everything is pushed to `main` (last commit `607082e`).

## What went badly

Getting a working Qwen key took most of the session, for three reasons stacked on top of each other:

1. The first key was a Token Plan key (it starts with `sk-sp-`). Token Plan is Alibaba's subscription for coding tools, and its keys do not work for normal API calls.
2. The next key was a workspace key (it starts with `sk-ws-`). Workspace keys only work at the workspace's own address, not at the general Singapore address the plan assumed. I found the address on the Workspaces page.
3. Several pastes put the wrong text into `.env`. The Copy buttons in the app's built-in browser do not reach the Mac clipboard, so each paste brought back an old snippet. A Reset in the console also cancelled a key you had just copied, and my own steps told you to reset more than once.

What fixed it was copying the key in your own browser and writing it into `.env` with a terminal command. I checked lengths and fingerprints of the key without ever printing it.

## What we learned

- The plan named "Qwen in the Singapore region" but did not say which kind of key or which address. Both turned out to matter more than the region.
- Both Qwen models think before they answer by default. A one-word reply used over 130 hidden tokens. The pipeline has to turn thinking off, or the cost estimate will be wrong.
- Jev rejected my guessed question format (a Noul question needs a `criteria` object). The Jev calls in Story 4.6 must follow the docs or the SDK, not memory.
- When a step needs you, one clear list up front works better than many small rounds. The key problem took about fifteen rounds.
